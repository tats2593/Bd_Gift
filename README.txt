# Mobile Gift Website

## Run locally
Open `index.html` in any modern browser.

## Customize
Open `script.js` and change:
- `name`
- `message`
- `signature`

To add real photos later, replace the `YOUR PHOTO` placeholder in `index.html` with an `<img>` tag and put the image file beside the HTML file.

## Make it shareable
Upload the folder to any static web host. Then send the resulting HTTPS link or turn it into a QR code.
